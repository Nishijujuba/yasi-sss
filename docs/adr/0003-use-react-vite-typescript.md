# Use React, Vite, And TypeScript

The exam simulation will use React with TypeScript and Vite, producing a static build that can run locally in a browser. React fits the growing interaction state around section navigation, audio controls, question overlays, marking feedback, transcript shadowing, and intensive listening exercises, while Vite keeps development and static asset generation straightforward.

## Consequences

The first version should use React state and narrowly scoped context providers. A larger external state-management library should only be introduced when shared state becomes difficult to reason about.
