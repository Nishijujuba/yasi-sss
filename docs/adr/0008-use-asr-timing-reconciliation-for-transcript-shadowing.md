# Use ASR Timing Reconciliation For Transcript Shadowing

Transcript Alignment will use ASR Timing Reconciliation as the primary workflow for producing Transcript Word Timings. The default ASR timing source is the local Whisper CLI with word timestamps enabled; `transcript.json` remains the Transcript Text Authority, and reconciliation maps ASR tokens onto official transcript token identities before final timing verification.

This supersedes ADR-0007 because the Qwen forced-alignment path can stall even after localization and short slicing, while timestamped ASR evidence can still support shadowing when official text authority, review trace, and release gates remain strict.

## Considered Options

- Continue with Qwen direct forced alignment: preserves a tool-specific alignment model, yet Section 01 has already shown timeout behavior across full, 180-second, 60-second, and 15-second attempts.
- Keep ASR only for localization before Qwen: keeps the previous boundary, yet still depends on the stalled forced-aligner stage for the final word times.
- Display ASR text directly: fastest path to timed text, yet it violates Transcript Text Authority and can change spellings, numbers, names, currency, and answer-bearing words.
- Use ASR Timing Reconciliation with local Whisper word timestamps: uses ASR word times as timing evidence, official transcript tokens as final identity, and review trace for risky or inferred mappings while avoiding the stalled Qwen model path.

## Consequences

The new `.agents/skills/yasi-asr-timing-reconciliation/` skill should own Whisper ASR generation, token reconciliation, interpolation rules, review artifact generation, run-level reporting, and final `transcript-timings.json` validation. Its working artifacts live under `D:\Project\yasi\待删除\yasi-asr-timing-reconciliation\`, grouped by section and model for temporary evaluation and review. The stable ASR evidence artifact is named `asr-timing-evidence.json`; it records engine, model, command, source audio identity, and word timestamps. The stable run report is named `reconciliation-report.json`; it records match statistics, review burden, highest-risk regions, provenance, and a three-state gate outcome: `ready-for-finalize`, `needs-review`, or `rerun-asr`. The default Whisper model should be selected by benchmark: the chosen model must complete the run, reach `anchorCoverage >= 0.95`, keep `unmatchedRate <= 0.02`, keep `pendingReviewRate <= 0.10`, and keep `longestUnanchoredGap <= 8` official tokens, then prefer the smallest passing model. The default token mapping algorithm is sequence alignment over normalized ASR and official tokens, followed by exact anchor extraction and bounded interpolation across gaps. Automatic interpolation is allowed only for gaps of at most 3 official tokens, with surrounding anchors at most 2.5 seconds apart, and no high-risk or answer-near token inside the gap. Review artifacts must classify each uncertain or provenance-bearing mapping with `matchType: exact | fuzzy | interpolated | split | merged | unmatched`. Benchmark review artifacts remain temporary, while the `alignment-review.json` used to produce a released verified `transcript-timings.json` must be promoted under `build/review/transcript-timing/` as the durable Transcript Timing Release Audit. Release validation must require `transcript-timings.json.reviewArtifact` to be a repo-root-relative path pointing to that durable audit artifact, verify that it exists, and reject pending or missing required review coverage. The final frontend contract remains `transcript-timings.json` with schema `yasi.transcript-timings.v1`; ASR engine, confidence, token alignment, interpolation, and review provenance belong in temporary generation artifacts and release audit artifacts, then only verified Transcript Word Timings enter the pack asset. Windows runners should set `PYTHONUTF8=1` when invoking Whisper, and the primary workflow should not load Qwen models. The old `yasi-forced-alignment` skill remains historical context and a source of reusable artifact and validation ideas, while ADR-0007 records the superseded Qwen slicing approach.
