# Section-Scoped Submission And Mistake Vocabulary Design

## Purpose

Improve the listening practice submission flow so accepted answers are revealed only for sections the learner has actually attempted, then add a Mistake Vocabulary Notebook for missed blank-answer words and phrases.

The feature keeps exam marking, answer reveal, and long-term review separate. Marking feedback explains what happened in the submitted attempt. The notebook stores only vocabulary mistakes worth practising again.

## Decisions

- An Attempted Listening Section is any Listening Section with at least one non-empty learner response.
- Submission is enabled only when the Practice Session has at least one non-empty answer.
- Submitting marks every Attempted Listening Section and excludes every unattempted section.
- Marking Feedback groups submitted results by Listening Section.
- Correct answers are hidden before submission and hidden for unattempted sections after submission.
- Mistake Vocabulary Capture adds only non-empty, incorrect Blank Responses from submitted Attempted Listening Sections.
- Choice mistakes and unanswered blanks stay in Marking Feedback and never enter the Mistake Vocabulary Notebook.
- The notebook keeps one card per normalized canonical term.
- The canonical term is the first accepted answer form in `answers.json`; other accepted forms remain visible as accepted variants.
- Repeating the same incorrect response through repeated submission does not increase `mistakeCount`.
- Changing the response and submitting another incorrect value creates a new capture event.
- Cards do not store question-number history.
- Mistake Vocabulary Cards use official audio clips generated at build time.
- `vocabulary.json` is maintained as static pack data with short common Simplified Chinese meanings generated by Codex and reviewed in the repository.
- The Practice Pack Home gets an independent `错题本` button.
- Notebook practice uses fixed queues: full ordered review or a one-time random sample of ten cards.
- Practice is active recall: play the official clip, type the English term, then reveal the correct spelling and short Chinese meaning.
- Correct practice records recent outcomes and mastery count; cards stay until the learner removes them manually.

## Current Code Surface

- `src/context/PracticeSessionContext.tsx` currently submits `pack.questions` and `pack.answers`, so it marks all 40 questions.
- `src/components/ExamWorkspace.tsx` currently passes `pack.questions` to `MarkingFeedback`, so right-side feedback can show answers outside the active section.
- `src/components/MarkingFeedback.tsx` currently renders a flat accepted-answer list.
- `src/lib/marker.ts` already supports marking any passed question subset, which is the right boundary for section-scoped submission.
- `src/lib/session.ts` stores one practice session in `localStorage` and should move to a new schema version when section-scoped results and capture signatures are added.
- The released pack currently has `manifest.json`, `questions.json`, `answers.json`, `overlays.json`, `transcript.json`, page images, and section MP3 files. It has no vocabulary asset and no answer-level audio clips.

## Section-Scoped Submission

At submission time, the app derives attempted sections from the current answers:

```ts
attemptedSections = sections where any question in section has trim(answer) !== ""
```

The submitted question set is every question whose `section` is in `attemptedSections`. The submitted answer-rule set is every answer rule whose `questionIds` are all inside the submitted question set. For the current IELTS pack, grouped rules stay inside one Listening Section.

For a learner who answers only Section 01:

- score denominator is `10`;
- right-side feedback shows only Section 01;
- the current Section 02/03/04 question pages show no accepted answers;
- wrong answered blanks in Section 01 can enter the Mistake Vocabulary Notebook;
- unanswered blanks in Section 01 count as unanswered in Marking Feedback and stay out of the notebook.

If the Practice Session has no non-empty answers, the submit button is disabled and displays a short Chinese hint such as `先完成至少一个答案`.

## Feedback UI

`MarkingFeedback` becomes section-aware:

- summary: `Raw score: x / n`;
- section groups in numerical order;
- each group displays wrong or unanswered questions from that section;
- accepted answers appear only inside submitted section groups;
- `下一错误题` focuses the next submitted incorrect or unanswered question.

The overlay answer reveal uses the same submitted result object. If the active section is outside `result.byQuestion`, `expectedAnswer(...)` returns nothing and the page does not leak accepted answers.

## Mistake Vocabulary Pack Data

The released pack gains a vocabulary asset:

```text
packs/cambridge-10/test-1/listening/
|-- vocabulary.json
`-- assets/
    `-- audio/
        `-- vocabulary/
            |-- ardleigh.mp3
            |-- newspaper.mp3
            `-- ...
```

`manifest.json` gains:

```json
{
  "assets": {
    "vocabulary": "vocabulary.json"
  }
}
```

`vocabulary.json` shape:

```json
[
  {
    "id": "photo-card",
    "term": "photo card",
    "normalizedTerm": "photo card",
    "acceptedVariants": ["photo cards"],
    "meaningZh": "照片卡",
    "audio": "assets/audio/vocabulary/photo-card.mp3"
  }
]
```

Coverage rule: every canonical term from single blank-answer rules must have one vocabulary item. Choice-only rules and grouped choice rules are excluded.

The Chinese meaning is a learning aid. It is never used by Strict Marking and never expands accepted answers.

## Build-Time Audio Clips

The builder adds source data for answer audio windows, separate from the transcript:

```json
[
  {
    "term": "Ardleigh",
    "normalizedTerm": "ardleigh",
    "section": 1,
    "startTime": 35.20,
    "endTime": 37.10,
    "paddingBefore": 0.15,
    "paddingAfter": 0.25
  }
]
```

The build pipeline uses FFmpeg to cut each clip from the released section MP3 into `assets/audio/vocabulary/*.mp3`. Validation blocks release when:

- a blank canonical term lacks a vocabulary item;
- a vocabulary item lacks an audio window;
- a clip path is missing;
- a clip duration is non-positive or unexpectedly long;
- `meaningZh` is empty;
- two vocabulary IDs collide after normalization.

The official clip is the audio authority for notebook practice. Browser text-to-speech is outside this design.

## Notebook State

Notebook state uses a separate localStorage key:

```text
yasi:cambridge-10:test-1:listening:mistake-vocabulary:v1
```

Suggested shape:

```ts
interface MistakeVocabularyNotebookState {
  version: 1
  packId: "cambridge-10-test-1-listening"
  cards: Record<string, MistakeVocabularyCardState>
}

interface MistakeVocabularyCardState {
  termId: string
  mistakeCount: number
  lastIncorrectResponse: string
  lastCapturedAt: string
  practiceAttempts: number
  practiceCorrect: number
  masteryCount: number
  lastPracticeResult: "correct" | "incorrect" | null
  lastPracticedAt: string | null
}
```

Cards store `termId`, counts, and recent practice outcomes. They do not store question-number history.

To support capture idempotence, the Practice Session can store opaque capture signatures such as:

```ts
capturedMistakes: Record<string, string>
```

where the key is a private question/result identifier and the value is the normalized incorrect learner response. This state prevents duplicate-submit inflation while keeping the notebook card free of question history.

Manual removal deletes the card from notebook state. If the learner later misses the same term again, the next capture creates a fresh card.

## Capture Flow

On submit:

1. Derive Attempted Listening Sections.
2. Mark only those sections.
3. For each submitted question result:
   - require `responseType === "blank"`;
   - require `actual.trim() !== ""`;
   - require `correct === false`;
   - derive canonical term from the first accepted answer form;
   - skip when the capture signature already matches the same normalized actual response;
   - upsert the notebook card by normalized canonical term.
4. Save Practice Session and notebook state.

This capture flow treats the notebook as a review queue, not as a full audit log.

## Home And Navigation

`PracticePackHome` adds a separate `错题本` button below the primary start/continue button. The button opens a new app view, for example:

```ts
type PracticeView = "home" | "workspace" | "mistakes"
```

When the notebook is empty, the view shows a concise empty state and a command to return home. It should not show example answers from the pack.

## Notebook View

The Mistake Vocabulary Notebook view contains:

- total card count;
- full ordered practice command;
- random ten-card practice command, disabled when there are no cards and sampling all cards when there are fewer than ten;
- card list with term, accepted variants, Chinese meaning, mistake count, mastery count, latest practice result, play clip command, and manual remove command;
- return-home command.

The ordered list should use stable local state order. A practical order is most recently captured first for the list and creation order for full ordered practice; if implementation chooses one order for both, that order must be documented in tests.

## Practice Queue

Starting a practice run creates a fixed queue:

- full ordered practice: every current card in the chosen order;
- random ten: a one-time random sample of up to ten cards.

During a run:

1. The current card plays its official clip.
2. The learner types the English word or phrase.
3. Submission uses the same normalization as Strict Marking.
4. The card shows correct spelling, accepted variants, and `meaningZh`.
5. The learner advances to the next card.

At the end, the app shows run results: correct count, incorrect count, and reviewed count. Correct answers increment `practiceCorrect` and `masteryCount`; incorrect answers increment only practice attempt state and latest result.

## Error Handling

- Missing vocabulary asset: block notebook entry with a clear pack diagnostic.
- Missing clip for a card: keep the card visible, disable play, and identify the missing asset path.
- Malformed notebook state: archive it under a timestamped localStorage key and start an empty notebook.
- Incompatible Practice Session schema: continue the existing archive-and-replace behavior.
- Empty notebook: show an empty state, with no random or full practice start.
- Audio playback failure: show the term and clip path, then keep the current card active.

## Testing

### Unit Tests

- attempted-section derivation from answers;
- section-scoped `markAnswers` wrapper marks only attempted sections;
- empty submission readiness disables submit;
- feedback groups results by section;
- unattempted section overlays do not show accepted answers;
- vocabulary canonical term uses the first accepted form and exposes variants;
- notebook capture excludes choice mistakes and unanswered blanks;
- capture idempotence ignores duplicate submit of the same incorrect response;
- changed incorrect response increments `mistakeCount`;
- notebook state archives malformed values;
- practice queue full order and random ten behavior;
- practice answer normalization and mastery tracking.

### Data Tests

- every blank canonical term has one vocabulary item;
- every vocabulary item has `meaningZh`;
- every vocabulary item audio path exists;
- every generated clip has a positive duration;
- vocabulary IDs are unique;
- `manifest.assets.vocabulary` resolves.

### Browser Tests

- before submission, no accepted answer text appears;
- after answering Section 01 and submitting, only Section 01 feedback appears;
- switching to Section 02 after Section 01 submission does not reveal Section 02 answers;
- wrong answered blank enters the notebook;
- unanswered blank stays out of the notebook;
- repeated submit of the same wrong answer does not increase `mistakeCount`;
- changing the wrong answer and resubmitting increases `mistakeCount`;
- home `错题本` button opens the notebook;
- full ordered practice completes with a run summary;
- random ten practice creates a fixed queue;
- manual remove removes the card from the notebook.

## Release Gate Additions

The practice pack release gate gains:

- vocabulary schema validation;
- blank-answer vocabulary coverage;
- official clip audio existence and duration validation;
- browser workflow coverage for section-scoped submission and notebook practice.

## Risks

- Official clip alignment is manual or semi-manual work until transcript timing exists. The builder must fail closed when an audio window is missing.
- Chinese definitions are generated by Codex, so review quality matters. They are learning aids only and must never influence scoring.
- Existing local sessions need a schema version change. The current archive behavior is acceptable because stale all-40 result objects would leak the old behavior.
